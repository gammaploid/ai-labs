## Description
This directory contains the source code for Lab 8, which focuses on logic programming with Prolog. The main file is `unix.pl`, which defines a knowledge base representing a simple UNIX-like file system structure.

## Requirements
A Prolog interpreter is required. SWI-Prolog is recommended.

## How to Run
1.  Start your Prolog interpreter (e.g., run `swipl`).
2.  Load the knowledge base by consulting the `unix.pl` file. In the Prolog prompt, type:
    ```prolog
    consult('Source/unix.pl').
    ```
3.  You can now run queries against the knowledge base.
